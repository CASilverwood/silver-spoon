A Reflection on the Process

At the moment, I'm experiencing the anxiety of, "this seemed easier than I feel it was supposed to be". I don't know if it means I did something wrong or not, but I do have some previous experience both with coding--through Introduction to Computer Science last summer and Video Game Writing last spring--and I'm familiar with GitHub, so maybe I know a little bit what I'm doing? My husband uses GitHub more than I do (although even then I don't think he uses it a whole lot), but he is a software developer, so it makes sense. One of the more difficult parts for me was the difference in language throughout GitHub--the fact that "commit changes" is just code-speak for "save", as an example. The process of putting everything into the repository felt similar to making a visual novel game in Ren'Py for Video Game Writing--all of the assets had to be in the same folder in order for the game's code to be able to find them, and the file names all had to be consistent throughout. Thinking about it more, I'm going to say it's because of probably Video Game Writing primarily that this assignment wasn't incredibly difficult. I will say that it's nice to be learning about different options of publishing things on the internet because I've wanted to make a website where I can publish some of my creative works but I really don't want to have to use something like WordPress or Wix, mostly because they're completely taken over by AI nowadays (and also because I don't want to have to pay a subscription for it).
